# Análisis del Titanic

## Descripción

En este proyecto se analiza el dataset Titanic utilizando Python.

No se utiliza Machine Learning.

Se realizan:

* Limpieza de datos.
* Análisis de datos.
* Creación de nuevas variables.
* Gráficas.

## Dataset

El dataset utilizado es `train.csv` de Kaggle.

## Variables nuevas

Se crearon:

* `FamilySize`: tamaño de la familia.
* `ViajaSolo`: indica si el pasajero viajaba solo.
* `TieneCabina`: indica si existe información de cabina.

## Análisis

Se analizaron:

1. Supervivencia de los pasajeros.
2. Supervivencia según sexo.
3. Supervivencia según clase.
4. Supervivencia según si viajaba solo.

## Tecnologías
